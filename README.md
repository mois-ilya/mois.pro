# mois.pro

Source for [mois.pro](https://mois.pro), my personal site and CV. One build produces the landing
page, a projects page, both language editions of the CV, and the two PDFs I attach to applications.

The deployed site is static. It has no JavaScript and no server-side code: Cloudflare serves the
files from `dist/` as they were built.

## Build it

The build needs [pandoc](https://pandoc.org/) and [Typst](https://typst.app/). The checks also use
Poppler; deployment uses Wrangler.

```sh
brew install pandoc typst poppler

make          # build both CV PDFs in dist/
make site     # build the complete site in dist/
make serve    # serve dist/ at http://localhost:8000
make check    # verify both PDFs
make watch    # rebuild the PDFs when their sources change
make deploy   # build and publish to Cloudflare
make clean
```

`make deploy` publishes to the live domain. Everything else is local.

## Turn job-search copy on or off

[`site.conf`](site.conf) contains the temporary state of the landing page:

```make
LOOKING_FOR_WORK := true
JOB_SEARCH_UPDATED := September 2026
```

Set `LOOKING_FOR_WORK` to `false` and rebuild. The status in the hero and the hiring-specific part
of the contact section will be omitted from the generated HTML; the rest of the page does not
change. The value can also be overridden for one build:

```sh
make site LOOKING_FOR_WORK=false
```

## Sources and outputs

| Path | Purpose |
| --- | --- |
| `src/index.html` | Hand-written landing page, including the conditional job-search fragments |
| `src/projects.md` | Projects page |
| `src/cv.md`, `src/cv.ru.md` | English and Russian CV sources |
| `template.html` | Wrapper for pages generated from Markdown |
| `template.typ` | CV PDF layout |
| `assets/` | Shared tokens and the two page layouts |
| `public/` | Portrait and icons copied to the site root |
| `dist/` | Complete deployable site, generated by `make site` |

The PDFs are generated into `dist/` with the rest of the deployable site. Markdown and the Typst
template remain the source of truth; generated binaries are not committed.

## Constraints carried by the build

The landing page stays hand-written HTML: it is a small layout, while the other pages are
documents and remain Markdown.

The CV stays in one column. A two-column version looked fine but produced a scrambled text layer:
dates were detached from the jobs they belonged to. `make check` runs `check-pdf.sh`, which extracts
the text from both PDFs
and verifies that every employer is still followed by its own dates. It also checks page size,
page count, metadata, tagging, and embedded fonts.

Pandoc reads the CV as `markdown-citations`; otherwise package names such as `@tonconnect/sdk` are
parsed as citations. External links are marked to open in a new tab by
[`filters/external-links.lua`](filters/external-links.lua).

## Deployment

[`wrangler.jsonc`](wrangler.jsonc) points Cloudflare Workers Static Assets at `dist/`. Both custom
domains use directory-style URLs, so `/cv`, `/cv/ru`, and `/projects` answer directly without a
trailing-slash redirect.
